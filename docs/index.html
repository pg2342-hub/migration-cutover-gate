Migration Cutover Gate

A go-live gate for moving a law firm's data out of its old practice management system and into Clio Manage. Rules clean every value and tie each batch back to the old system's own report, Claude makes the calls rules cannot, and a batch loads only when every number ties.

Why the numbers come first

A migration is finished when the firm has signed the numbers, not when the data has loaded. The old system's own reports are the answer key: client and matter counts, unbilled hours, what each matter still owes, and what each matter holds in trust. A batch that disagrees with its report is held, with the line that does not tie and both numbers, and nothing is written.

Claude never supplies an amount, ID or date. It picks only among clients already in the batch, and code checks every pick. Every request is validated against Clio's published API schema before it is sent. The recorded run cost about $0.019 and 5.6 s of model time per batch (two calls: the mapping, then the message to the firm), plus $0.43 for the judge across all 90 batch runs.

What each check caught

How many of the 30 batches failed each check. The spreadsheet import breaks IDs, guesses clients and loads batches that do not tie; the Claude pipeline missed one check once in 90 batch runs.

A check at zero never failed on either setup in this run.

Who decides a matter's client

Match it

Exactly one client in the batch fits.

  • A blank name with the client ID filled
  • "ACME Corp" for ACME Corporation
  • A married name with the same email on file

Send it to a person

A wrong client attaches a case file to the wrong person.

  • "Smith, J." with two Smiths on file
  • The same client entered twice
  • A client who is not in this batch

Attaching a matter to the wrong client is critical and blocks go-live on its own. Sending a clear match to review costs a person a minute, so that miss only holds rollout at partial. The one miss in this run: batch a06, where a clear match went to review on one of three runs.

Data

All firms, names, emails, phone numbers and amounts are constructed: 30 batches from a fictional 12-lawyer firm. Request schemas come from Clio's published API v4 OpenAPI spec. Claude's replies are a recorded live run from November 23, 2026, replayed through the current code; cleaning, reconciliation, guardrails and the load always run for real.

Run it yourself

Python 3.10+, no API key needed to replay.

pip install -e ".[dev]"
pytest -q
